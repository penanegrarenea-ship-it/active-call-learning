HTTP 监听和 SIP 监听

供以后重开。端口以正在用的配置为准。不是官方文档，也不表示已经掌握，也尚未运行。

  • http_addr：网页和 API 的 HTTP 监听地址（完整 IP + 端口）。
  • addr：SIP 绑定 IP；udp_port：SIP 信令使用的 UDP 端口（指南还写它也用于 RTP）。
  • 同一提交里数字并不统一：示例文件与 Docker 为 8080 / 13050；中文指南基础配置写 UDP 默认 25060，同文 FAQ 又写 SIP 13050；Twilio 指南示例为 5060 / 5061。不要合成一个官方默认值。
  • 命令行 --http / --sip 会覆盖文件。以实际启动为准。
  • 官方示例录音默认开启；课堂先关掉。HTTP 控制面未描述 REST 令牌鉴权，不对公网开放。
