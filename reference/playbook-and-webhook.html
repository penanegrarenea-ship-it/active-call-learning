Playbook 与 Webhook 处理器

供以后重开。入口和处理器不是一层。不是官方文档，也不表示已经掌握。

  • 入口：声音怎么接进来（浏览器 WebRTC、SIP、程序推音频）。
  • 处理器：接进来之后按什么逻辑处理。
  • Playbook：本地 Markdown + YAML 前置，用正文声明场景。
  • Webhook 处理器：外部 HTTP 服务。配置指南写的是，把呼入请求转过去，由它决定如何处理。
  • Playbook 里的 HTTP 工具（如官方 webhook_example.md）不是呼入 Webhook 处理器。

已读文档未写清：外部服务是否接手整段语音、是否每段音频都经 HTTP 发出、完整返回约定，以及「呼入处理配置」这一节（开篇为两种 SIP 呼入处理方式）是否同样用于另外两条入口。均待核实。
