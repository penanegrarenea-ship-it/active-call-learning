Hello Playbook：先分清 YAML 前置和正文

约 3 分钟。本课只记一件事：Playbook 开头的 YAML 前置是配置，后面的 Markdown 是场景或角色正文；改开场欢迎语，先找前置里的 greeting。下面是官方文件的摘录，本课只读、不运行。

官方教程写道：Playbook 采用 Markdown 格式，用 Front Matter（YAML）定义引擎参数，用 Markdown 内容定义流程、场景和提示词。本课对照的是同提交里真实存在的 config/playbook/hello.md。该提交的 Playbook 目录里没有 demo.md，不要拿它当作业。

摘录一：YAML 前置里和本课有关的几行。行与行之间有省略，不能当成完整文件，也不可直接运行。

---
asr:
  provider: "sensevoice"
  # sensevoice is local provider
  # ...
llm:
  provider: "aliyun"
  # ...
tts:
  provider: "supertonic"  # aliyun, tencent, supertonic
  # supertonic is local provider
  # ...
greeting: "Hello, how can i help you?"
---

摘录二：后面的 Markdown 正文（同样不完整）

# Role and Purpose
You are an intelligent, polite AI assistant. Your goal is to help users with their inquiries efficiently.

两段中间隔着结束前置的 ---。教程把 greeting 放在 YAML 前置的交互配置里；这份 hello 的开场欢迎语就是这一行。正文从 # Role and Purpose 起，写的是助手角色。这份文件里没有 # Scene: 小节，多场景写法下一课再讲。

文件注释写 sensevoice、supertonic 是本地提供者，但 llm 写的是 aliyun，可能走云服务并产生费用。不要把这份示例当成已经跑通的免费离线全套。完整文件里还有录音等项，本课不展开。只做静态阅读：不运行 active-call，不发起呼叫，不下载模型。
